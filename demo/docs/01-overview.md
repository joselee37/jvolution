# 01 — 게임 개요 (Game Overview)

## 컨셉 (Concept)

**Sonar Tamagotchi**는 CRT/소나(sonar) 관측소를 테마로 한 가상 펫(virtual
pet) 게임이다. 플레이어는 심해 관측 기지의 운영자(operator)가 되어, 소나
스코프 안에서만 관측되는 생명체(creature) 한 개체를 돌본다.

생명체는 직접 보이지 않는다. 소나 펄스(pulse)가 훑고 지나간 자리에서만
도트(dot)로 잠깐 빛났다가 포스퍼(phosphor)처럼 감쇠하며 사라진다. 모든
상호작용은 군용 계측기풍 화면과 텍스트 터미널(terminal)을 통해 이루어진다.

게임은 단일 생명체를 키우는 가상 펫 루프에, 주변을 떠도는 NPC 피어(peer)
와의 가위바위보(RPS) 전투를 결합한 구조다.

## 코어 게임플레이 루프 (Core Loop)

```
        ┌─────────────────────────────────────────────┐
        │                                             │
        ▼                                             │
   ┌─────────┐   케어 액션이 진화 게이지를 채움          │
   │  케어    │   (먹이기·놀기·청소·훈련 등)             │
   │  CARE   │                                         │
   └────┬────┘                                         │
        │ evolveProgress 누적                          │
        ▼                                             │
   ┌─────────┐   게이지가 가득 차면 다음 단계로          │
   │  진화    │   (egg→larva→juvenile→adult)            │
   │ EVOLVE  │                                         │
   └────┬────┘                                         │
        │                                             │
        ▼                                             │
   ┌─────────┐   레이더로 주변 피어를 탐지              │
   │  탐지    │   피어가 도전을 걸어오거나 직접 도전      │
   │ DETECT  │                                         │
   └────┬────┘                                         │
        │                                             │
        ▼                                             │
   ┌─────────┐   가위바위보 전투 — 승리 시 진화 게이지   │
   │  전투    │   가속, 피어와의 유대(bond) 변동         │
   │ BATTLE  │                                         │
   └────┬────┘                                         │
        │ 결과가 케어 스탯에 반영 ──────────────────────┘
        ▼
   ┌─────────┐   세대 리셋 시 이전 개체는 비석(epitaph)
   │  계보    │   으로 아카이브 → 새 알(egg)로 다시 시작
   │ LINEAGE │
   └─────────┘
```

핵심 순환은 **케어 → 진화 → 탐지 → 전투**이며, 이 과정에서 쌓인 결과가
다시 케어 스탯으로 되돌아온다. 생명체가 수명을 다하거나 플레이어가 리셋
하면 그 개체는 **계보(lineage)** 에 비석으로 보존되고, 새 세대가 시작된다.

## 메인 화면 (Views)

게임은 4개의 메인 화면을 가지며, 한 번에 하나만 메인 베젤(bezel)에
표시된다. 화면 전환은 터미널 명령어로 이루어진다.

| 화면 | 이름 | 내용 | 진입 명령어 |
|------|------|------|-------------|
| 소나 (sonar) | SONAR-OBS | 생명체 관측 — 기본 화면 | `sonar`, `back` |
| 계보 (lineage) | LINEAGE-ARCHIVE | 세대 계보 트리 | `tree` |
| 레이더 (radar) | LRRS-RADAR | 주변 피어 레이더 스코프 | `scan`, `peers`, `radar` |
| 전투 (battle) | ENGAGEMENT | 피어와의 전투 콘솔 | `accept`, `challenge <name>` |

전환 규칙:

- 기본 화면은 **소나**다. 게임은 항상 소나 화면으로 시작한다.
- 소나·계보·레이더는 터미널 명령으로 자유롭게 오간다.
- **전투** 화면은 전투가 시작될 때만 진입하며, 전투가 끝나면 자동으로
  소나 화면으로 복귀한다.
- 전투 중에는 화면 전환이 잠긴다(상세는 [04](./04-battle.md),
  [05](./05-terminal.md) 참조).
- 피어가 도전을 걸어오면(근접 경보) 어느 화면에 있든 메인 베젤 위에
  경보 오버레이(overlay)가 뜬다.

## 진행 단위 (Progression Units)

게임은 다음 단위로 진행 상태를 측정한다.

| 단위 | 영어 | 설명 |
|------|------|------|
| 케어 사이클 | care-cycle | 케어 액션 1회를 수행할 때마다 1씩 증가하는 카운터. 생명체가 받은 보살핌의 총량을 나타낸다. |
| 일수 | age / days | 생명체의 나이(일 단위). 소나 화면에 `AGE nnD`로 표시된다. |
| 세대 | generation | 몇 번째 개체인지. 리셋할 때마다 1씩 증가한다. |
| 진화 단계 | stage | egg → larva → juvenile → adult의 4단계. |
| 진화 진척도 | evolveProgress | 다음 단계까지의 진행도(0~1). 1에 도달하면 진화 가능. |

생명체의 시작값은 1세대(gen 1), egg 단계, age 0, cycles 0이다. 자세한
스탯 초기값은 [02](./02-creature-care.md)를 참조한다.

## 운영자 설정 (Operator)

게임 세계관상 플레이어는 고정된 운영자 정체성을 가진다(터미널 `whoami`
로 확인). 이는 연출용 고정 텍스트이며 게임플레이에 영향을 주지 않는다.

- 운영자 ID: `NAUTILUS-7`
- 권한 등급: `TIER 3 — CARETAKER`
- 근무지: `CIC // ABYSSAL OBSERVATION POST`
