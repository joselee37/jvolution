# 06 — UI·비주얼·CRT 명세 (UI & Visual)

## 화면 레이아웃 (Screen Layout)

게임은 세로형 모바일 프레임(portrait mobile frame)을 기준으로 설계되었다.
기준 캔버스는 폭 402 × 높이 874 단위다. 화면은 위에서 아래로 다음 영역이
세로로 쌓인다.

| 영역 | 높이(단위) | 내용 |
|------|-----------|------|
| 상태바 (status bar) | 60 | 시각·신호·배터리 등 OS 상태 표시줄. |
| 헤더 (header) | 32 | 게임 타이틀(`NAUTILUS`), 버전, `LINK`/`REC` 태그. |
| 메인 베젤 (main bezel) | 가변 (내부 1:1 정사각형 362 + 베젤 크롬 약 65) | 4개 메인 화면 중 하나를 표시. |
| 터미널 (terminal) | 315 | 텍스트 콘솔. |
| 홈 인디케이터 (home indicator) | 34 | OS 하단 제스처 바. |

레이아웃 규격(구현 비종속):

- **메인 베젤의 내부 표시 영역은 1:1 정사각형**이다(362 × 362). 소나·계보·
  레이더·전투 화면은 모두 이 정사각형 안에 그려진다.
- 베젤은 내부 정사각형 둘레에 물리 계측기풍 크롬(chrome) — 라벨 스트립,
  볼트(bolt), 인디케이터 LED — 을 두른다.
- 터미널 폭은 프레임 폭에서 좌우 여백을 뺀 값이다(기준값 386).
- 위 수치는 기준 비율이며, 다른 해상도/종횡비로 스케일할 때는 1:1 메인
  베젤과 영역 간 상대 비율을 유지한다.

## 베젤 (Bezel)

메인 화면을 감싸는 베젤은 3종이며, 설정 패널에서 선택한다(기본값
`military`).

| 베젤 | 영어 | 외형 특징 |
|------|------|-----------|
| 밀리터리 | military | 올리브-그린 군용 계측기. 금속 볼트 4개, 라벨 스트립, 인디케이터 LED. 차가운 회녹색 톤. |
| 빈티지 | vintage | 갈색 우드/베이클라이트 톤. 따뜻한 색의 볼트·라벨. |
| 미니멀 | minimal | 크롬 없는 단순 검정 프레임. 얇은 테두리만. |

베젤 라벨 스트립은 현재 화면에 따라 텍스트가 바뀐다 — 예: 소나에서는
`SONAR-OBS · MK.III · <단계>`, 전투에서는 `ENGAGEMENT · CH.07 · R.<턴>`.

## 색상 시스템 (Color System)

게임의 모든 발광색은 단일 색조(hue) 변수를 중심으로 한 **포스퍼
(phosphor) 팔레트**로 만들어진다. 색조 하나만 바꾸면 텍스트·게이지·LED·
스윕·블립이 일제히 같은 색으로 이동한다.

**테마(theme) 3종 — 색조 값:**

| 테마 | 영어 | 색조(hue) | 인상 |
|------|------|-----------|------|
| 그린 | green | 155 | 클래식 인광 녹색 (기본값). |
| 앰버 | amber | 75 | 호박색 — 빈티지 모니터. |
| 블루 | blue | 220 | 차가운 청색. |

**경보색 (alert):** 피어가 도전을 걸어오면 색조가 **빨강(red, hue 25)**
으로 강제 전환된다([03](./03-peer-radar.md)). 요청이 해소되면 원래 테마
색으로 복귀하며, 이 전환은 부드럽게 보간(interpolate)된다.

**포스퍼 팔레트 컨셉(oklch 기반):** 색은 oklch 색공간에서 `밝기 / 채도 /
색조`로 정의된다. 색조는 위 테마 값을 공유하고, 명도·채도 단계로 위계를
만든다.

| 단계 | 용도 | 컨셉 |
|------|------|------|
| phos | 주요 발광 텍스트·강조 | 가장 밝고 채도 높음. |
| phos-mid | 보조 텍스트·라벨 | 중간 밝기. |
| phos-dim | 비활성·흐린 텍스트 | 어두움. |
| phos-grid / phos-faint | 그리드선·눈금 | 가장 어둡고 반투명. |

## CRT 연출 레이어 (CRT Effect Layers)

모든 화면 위에는 CRT 모니터 질감을 내는 연출 레이어가 합성된다.

| 레이어 | 영어 | 내용 |
|--------|------|------|
| 배경 글로우 | crt-bg | 중심이 밝은 방사형 그라데이션. |
| 그리드 | crt-grid | 주(major)/부(minor) 격자선 — 소나 모눈 느낌. |
| 눈금 | crt-ticks | 상하단 점선 자(ruler) 눈금. |
| 스캔라인 | crt-scanlines | 가로 줄무늬 — CRT 주사선. |
| 스캔밴드 | crt-scanband | 위→아래로 천천히 흐르는 넓은 밝은 띠(약 7초 주기). |
| 노이즈 | crt-noise | 프랙탈 노이즈 정전기. |
| 비네트 | crt-vignette | 가장자리를 어둡게. |
| 플리커 | crt-flicker | 드물게 깜빡이는 미세 명멸(약 2.6초 주기). |

**강도 파라미터:** 설정 패널의 CRT 강도(crt) 값과 스캔라인·노이즈 토글이
다음을 제어한다.

| 파라미터 | 산출 규칙 | 의미 |
|----------|-----------|------|
| 스캔라인 강도 | 스캔라인 ON일 때 `0.18 × crt`, OFF면 0 | 줄무늬 진하기. |
| 노이즈 강도 | 노이즈 ON일 때 `0.12 × crt`, OFF면 0 | 정전기 진하기. |
| 글로우 강도 | `crt` 값 그대로 | 발광 번짐 세기. |

`crt`(CRT 강도)는 사용자가 0~1.4 범위로 조절한다. 즉 스캔라인·노이즈는
각자의 토글로 켜고 끄되, 진하기는 공통 CRT 강도에 비례한다.

## 설정 패널 (Tweaks Panel)

설정 패널은 게임 위에 떠 있는 보조 패널로, 비주얼·연출·생명체 옵션을
실시간 조절한다. 노출 항목과 값 범위는 다음과 같다.

| 섹션 | 항목 | 종류 | 값 / 범위 | 기본값 |
|------|------|------|-----------|--------|
| Display | Theme | 선택 | green / amber / blue | green |
| Display | CRT intensity | 슬라이더 | 0 ~ 1.4 (0.1 단위) | 0.7 |
| Display | Scanlines | 토글 | on / off | on |
| Display | Noise / static | 토글 | on / off | on |
| Bezel | Housing | 선택 | military / vintage / minimal | military |
| Creature | Species | 선택 | ghost / blob / jelly / squid / pixel | ghost |
| Sonar | Pulse period | 슬라이더 | 2 ~ 12초 (0.5 단위) | 5 |
| Sonar | Phosphor decay | 슬라이더 | 0.3 ~ 4초 (0.1 단위) | 1 |
| Audio | SFX | 토글 | on / off | off |
| Care | Hatch new egg | 버튼 | — | (리셋 실행) |

- **Pulse period** — 소나 펄스가 자동으로 발사되는 주기. 짧을수록 생명체가
  자주 보인다.
- **Phosphor decay** — 펄스가 지나간 뒤 도트가 식는 시간 상수. 길수록
  잔상이 오래 남는다.
- **Hatch new egg** — 터미널 `reset`과 같은 동작(현 세대 아카이브 + 새 알).

## 타이포그래피 (Typography)

게임은 3종의 모노스페이스 폰트를 용도별로 쓴다.

| 폰트 | 분류 | 용도 |
|------|------|------|
| VT323 | 픽셀 (pixel) | 큰 제목, 무드 라벨, 전투 태그 등 강조 텍스트. 도트 매트릭스 느낌. |
| JetBrains Mono | 모노 (mono) | 터미널 본문, readout, 수치 표시 등 정보 텍스트. |
| Share Tech Mono | 테크 (tech) | 보조 기술 라벨용. |

**글로우 효과:** 강조 텍스트에는 포스퍼 색의 텍스트 글로우(text glow)가
적용되어 CRT 발광처럼 번진다. 글로우 세기는 위계(phos / phos-mid)에 따라
달라진다.

## 기타 연출 메모

- **토스트(toast):** 케어 액션 등의 즉시 피드백은 화면 상단에 작은 배너로
  약 1.4초간 떴다가 사라진다.
- **소나 펄스 스윕:** `ping` 시 소나 화면을 가로지르는 밝은 스윕 띠가
  약 1.6초에 걸쳐 지나간다.
- **HUD 크롬:** 각 화면 모서리에는 ㄱ자 브래킷, 타깃 브래킷 등 계측기풍
  장식 요소가 배치된다.
- **전투 HP 바:** 데미지가 들어오면 HP 바가 짧게 흔들리고, 피격된 생명체에
  밝기 플래시가 인다.
