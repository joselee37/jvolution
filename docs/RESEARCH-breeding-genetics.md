# 번식·유전 계보 시스템 설계 패턴 리서치

> **목적:** jvolution(Kotlin Multiplatform, Android/iOS, 진화 테마)에 번식(breeding) + 유전자 계보(genetic lineage) 시스템을 **구현하기 위한 기술 설계 패턴** 조사.
> 유전자가 개체의 (1) 외형/절차적 생성, (2) 스탯/수치 속성, (3) 성격/행동 AI, (4) 계보/번식 메타게임 전반에 영향을 주는 구조를 목표로 함.
>
> **작성일:** 2026-06-16
> **생성 방식:** deep-research 워크플로(17개 출처 → 80개 주장 추출 → 25개 검증 → 23개 확정, 2개 반증). 적대적 교차검증(claim별 3표 중 2표 반증 시 폐기).
> **상태:** 리서치 산출물 — 구현 결정 전 참고 자료. 미해결 질문은 §8 참고.

## 1. 핵심 골격: 2단계 유전형→표현형 매핑

```
게놈(genome, 직렬화 가능·고정 구조)  →  [결정론적 발생 함수]  →  표현형(외형 + 스탯 + 행동)
```

검증된 모든 시스템이 이 한 가지 골격을 공유한다: **고정 길이의 직렬화 가능한 게놈을 결정론적(deterministic) 발생 함수에 통과시켜 외형·스탯·행동을 한꺼번에 산출하는 2단계 유전형→표현형(genotype→phenotype) 매핑.** 이 패턴은 도킨스 바이오모프(1986) → 칼 심스(1994) → Creatures(1996) → NEAT를 거쳐 최신 번식 게임까지 끊기지 않고 이어진다.

이 구조가 강력한 이유: **게놈만 저장·교배·돌연변이시키면 되고, 표현형은 매번 순수 함수로 재생성**된다. 저장 용량이 작고, 같은 게놈은 항상 같은 개체를 만들며(결정론), 교배·계보 로직이 표현형과 완전히 분리된다.

**최소 참조 구현 = 도킨스 바이오모프(1986).** 정확히 9개의 정수 게놈으로, g1~g8이 8개의 2D 벡터를 정의해 재귀 그리기 함수(`DrawBiomorph`)에 입력되고, g9가 재귀/발생 깊이(종료 전 단계 수)를 설정한다. 외형은 선분의 길이·위치·각도를 정하는 유전자에서 창발한다. *(PLOS Comp Biol 2024 / Wikipedia / Wiley CGF, 검증 3-0)* — jvolution이 복사할 수 있는 **가장 작은 실용 단위**: 고정 정수 배열 → 결정론적 절차 생성기.

## 2. 역사적 계보 — 각 시스템에서 이식할 것

| 시스템 (연도) | 게놈 구조 | jvolution에 가져올 것 | 출처 신뢰도 |
|---|---|---|---|
| **Biomorphs** (1986) | 정수 9개 | 최소 2단계 매핑 + 가장 단순한 번식 루프 | 높음(1차 논문) |
| **Karl Sims** (1994) | 방향 그래프(노드=신체부위, 엣지=관절), 재귀 | 절차적 **신체 형태** 생성 + 신체·뇌 통합 게놈 | 높음(저자 원논문, 2-1) |
| **Creatures** (1996) | "Digital DNA" — 뇌(엽lobe·수상돌기·뉴런)·생화학·외형 | **행동 AI를 유전 가능한 컴포넌트로** 만드는 모델 | 보통(위키, 무논쟁) |
| **Spore** (2008) | 골격 그래프 위 암시적 표면(metaball) | 편집 가능한 골격 위 **실시간 절차적 스키닝** | 높음(1차 + Hecker 노트) |
| **NEAT** | 연결 유전자의 선형 리스트 + 노드 유전자 | **직렬화가 가장 쉬운** 진화형 신경망 게놈 | 높음(1차 논문) |

**세부 사항**

- **Karl Sims (1994):** 방향 그래프에서 노드=방향성 박스 신체부위, 엣지=관절, 그래프 내 재귀가 반복/프랙탈 신체부위를 만든다. 핵심은 **하나의 중첩(nested) 그래프가 형태와 제어 신경망을 동시에 인코딩**한다는 점 — 각 형태 노드가 내부에 신경 그래프를 품는다. 신체와 행동이 하나의 유전 구조로 묶인다. ⚠️ 이 항목은 2-1 검증이며 용어 주의: 원논문은 "단일 재귀 그래프"가 아니라 **중첩 그래프**다. 구현 시 [원논문](https://www.karlsims.com/papers/siggraph94.pdf)을 직접 읽을 것.

- **Creatures (1996):** "키우고 번식시키는 디지털 생명체" 장르의 시초로, 이후 번식 게임이 물려받은 루프(부화 → 성장 → 번식 → 죽음)를 정립했다. 각 Norn의 뇌·생화학·외형이 시뮬레이션된 게놈으로 결정되며, 게놈이 **뇌 구조(엽, 수상돌기, 뉴런)를 직접 인코딩**한다(약 952 뉴런/5000 연결/9 엽 — Alan Zucconi 분석). 스크립트가 아니라 **유전되는 신경망**이 행동을 만든다는 게 핵심. ⚠️ 단, 제작자 Steve Grand 본인이 이것은 개체의 개성·번식을 위한 설계이지 "진화 기반 시뮬레이션이 아니다"라고 밝혔다.

- **Spore (2008):** 플레이어가 골격을 편집·부위를 붙였다 떼는 에디터가 요구되므로, **3D 골격 그래프 둘레에 암시적 표면(metaball)을 실시간 재생성**하는 절차적 스키닝을 쓴다. ✅ ("Spore는 절차 생성이 아니다"라는 주장은 0-3으로 **반증**됨 — 부위는 플레이어가 놓지만 스키닝은 진짜 절차적이다.)

## 3. 유전·교배 알고리즘: 세 가지 패러다임 (각각 → 구체적 자료구조)

| 패러다임 | 자료구조 | 대표작 | jvolution 적합도 |
|---|---|---|---|
| **멘델리안 이배체(diploid)** | 고정 N개 좌위(locus) 배열, 각 좌위 = 대립유전자 2개(부모 각 1개) | Niche | ⭐ 진화·번식 테마에 최적 |
| **혼합/불완전우성(blending)** | 위와 동일하되 좌위별 발현 규칙이 "섞임" | Niche 털색, Wobbledogs | 좌위별 옵션으로 혼합 |
| **다유전자형 스탯별(polygenic)** | 스탯마다 독립 값, 부모 랜덤 선택 | Pokémon IV | 스탯 도메인에 적합 |

- **멘델리안 이배체 — Niche가 최고의 현대 레퍼런스:** 21개 좌위의 고정 DNA 문자열, 각 좌위에 대립유전자 2개(엄마/아빠 각 1개, 부모의 두 대립유전자 중 어느 것이 전달될지는 50%). 총 21개 범주에 111개 유전자. 좌위 타입별 매핑 규칙: **완전우성**(우성만 발현, 대부분의 유전자, 예: 눈 색), **불완전우성/혼합**(섞임, 예: 검정+흰색 털 = 회색), **공우성**(둘 다 동시 발현, 예: 각 발이 부모 한쪽 유전자를 표시). X-연관 예외도 있음(혈액 응고 — 수컷은 대립유전자 1개 + "No Gene" 슬롯). *(Niche Fandom + Steam 가이드, 3-0)* → **고정 21좌위 대립유전자쌍 배열로 그대로 구현 가능.**

- **다유전자형 — Pokémon (3세대+):** 기본적으로 자식은 정확히 **3개의 IV(개체값)를 상속**하며, 각각 서로 다른 스탯에 대해 **랜덤하게 선택된 부모**로부터 받는다(중복 선택 시 덮어씀). "운명의 매듭(Destiny Knot)" 아이템은 상속 IV 수를 3 → 5로 **결정론적으로 증가**시킨다. *(Bulbapedia + PokemonDB, 3-0)* ✅ ("운명의 매듭이 *착용한 부모*의 IV 5개를 강제로 물려준다"는 주장은 0-3 **반증** — 결정되는 건 *개수(5)*뿐이고, *어느 스탯·어느 부모*인지는 랜덤이다.)

- **혼합 + 환경 채널 — Wobbledogs:** ① 세대 교배 루프(개 2마리 선택 → 교배 → 원하는 방향으로 유전자를 몰아갈 때까지 반복; 각 대립유전자쌍은 부모에게서 하나씩, **세대마다 돌연변이 ↑·안정성 ↓**), ② 비(非)멘델리안 환경 채널: **먹이(장내 세균 gut flora)가 발생 분기점(번데기/우화)에서 표현형 돌연변이를 유발**(47종 장내 세균, 각각 특정 돌연변이 보유). *(Game Developer 개발자 인터뷰 + Fandom, 3-0)* → 혼합 유전과 직교(orthogonal)하는 환경 돌연변이 시스템이 공존하는 좋은 사례.

## 4. 돌연변이 모델 (난이도순)

1. **최소형 (Biomorphs):** 단일 부모, 교배 없음, 9개 유전자 중 하나를 +1 또는 -1. 가장 단순한 번식 게임 루프 그 자체. *(3-0)*
2. **구조형 (NEAT):** 세 연산자 — *add-connection*(연결되지 않은 두 노드 사이 새 연결 1개, 랜덤 가중치), *add-node*(기존 연결을 분할, 옛 연결 비활성화 + 새 연결 2개 추가), *가중치 섭동*(매 세대 연결별로 perturb 여부). *(Stanley & Miikkulainen EC02 1차 논문, 3-0)*
3. **환경 구동형 (Wobbledogs):** §3 ② 참고. 식단 → 발생 분기점 표현형 변형.

⚠️ **반드시 알아둘 설계 함정 — 표현형 편향(phenotype bias):** 어떤 유전형→표현형 매핑에서도 일부 표현형은 랜덤 돌연변이로 **수십~수백 배(orders of magnitude) 더 자주 등장**한다. 돌연변이는 표현형 공간을 균일하게 샘플링하지 *않는다*(발생/단순성 편향). 이는 번식 공간이 얼마나 다채롭고 "발견할 맛이 나는지"를 좌우하므로, 돌연변이율·우성 분포 튜닝의 핵심 고려사항이다. *(PLOS Comp Biol 2024 1차, 3-0)*

## 5. NEAT — 직렬화 가장 쉬운 진화형 행동 게놈

행동 AI를 *유전*시키고 싶을 때 가장 이식하기 좋은 자료구조: **연결 유전자의 선형 리스트**(각각 = in-node, out-node, weight, enable bit, **innovation number**) + 노드 유전자. 고정 필드 레코드의 평평한 리스트라 직렬화가 자명하다. **혁신 번호(innovation number)**가 위상(topology)이 다른 게놈 간 교배를 위상 분석 없이 가능하게 한다 — 같은 혁신 번호를 가진 유전자(matching)는 랜덤 교차, 불일치(disjoint/excess) 유전자는 더 적합한(fit) 부모에게서 상속. *(EC02 1차 논문, 3-0)*

다만 모바일에서 풀 NEAT는 튜닝·결정론 유지가 어렵다(§6 권장안 참고).

## 6. jvolution 권장 아키텍처 (Kotlin Multiplatform)

> 아래는 검증된 패턴을 KMP 환경에 맞춰 **종합한 구현 권고**이며, 인용된 사실(§1–5)과는 구분된다.

**(a) 게놈 = 고정 구조·이배체·`kotlinx.serialization` 직렬화.** 진화/번식 테마에는 Niche식 **대립유전자쌍 리스트**가 스윗스팟 — 멘델리안 상속 + 좌위별 우성 규칙을 공짜로 얻고 완전 결정론적.

```kotlin
@Serializable
data class Allele(val locusId: Int, val value: Int)        // 정수값 → 결정론

@Serializable
data class GenePair(val locus: Locus, val maternal: Allele, val paternal: Allele)

@Serializable
data class Genome(val version: Int, val pairs: List<GenePair>)  // 고정 길이

enum class Dominance { COMPLETE, INCOMPLETE_BLEND, CODOMINANT }

@Serializable
data class Locus(val id: Int, val domain: Domain, val dominance: Dominance)

enum class Domain { APPEARANCE, STAT, BEHAVIOR }   // 한 게놈이 4개 도메인에 영향
```

**(b) 표현형 = 순수 결정론 함수** `fun express(g: Genome): Phenotype`. 외형 파라미터·스탯·행동 파라미터를 한 번에 산출. **양 플랫폼에서 동일 결과가 나와야 하므로** 유전자 값은 정수/고정소수점으로 두고, 재생산 시 난수는 **시드 기반 portable PRNG**(직접 구현하거나 결정론 보장 라이브러리)를 쓸 것 — replay/계보 재현이 필요하면 `kotlin.random` 플랫폼 기본값과 `Double` 비결정성에 의존하지 말 것. **이것이 KMP 핵심 리스크다.**

**(c) 도메인별 설계**

- **외형:** 2D 재귀/벡터(Biomorph식)로 시작 — 저렴하고 완전 결정론적이라 모바일 친화. 유전자 → 선분 길이/각도/개수/색. 3D 부위조립·암시적 표면(Spore/Sims식)은 아트 방향이 요구할 때만, 성능·툴링 비용을 감수하고.
- **스탯:** **다유전자형 합산**(스탯 1개 = 여러 유전자 기여의 합) 권장 — 단일 유전자=단일 실패점을 피하고 종형 분포를 줌. 이배체 게놈과도 자연스럽게 통합.
- **행동 AI:** 초기엔 풀 NEAT 대신 **유전자 가중 파라미터화 행동**(유전자가 고정된 행동 트리/효용 AI의 가중치·임계값을 설정) 권장 — 모바일에서 튜닝·결정론이 쉬움. 창발적 행동을 원하면 NEAT를 후속 목표로.
- **계보 메타:** 개체마다 부모 ID 저장(혈통 DAG), **Wright의 근친계수(inbreeding coefficient)** 계산, 다양성 지표 추적. ⚠️ 이 부분은 검증된 출처가 **전무** — 직접 설계해야 하며, Wright 계수를 출발점으로.

**(d) 교배:** 좌위별로 각 부모에게서 대립유전자 하나씩 선택(이배체 재조합) + 대립유전자 소폭 섭동 돌연변이 + 드문 구조 변이. 깊이를 원하면 Wobbledogs식 환경 채널 추가.

## 7. 주의사항 (반드시 읽을 것)

- **출처 등급:** 게임 메커니즘(Niche·Pokémon·Wobbledogs·Creatures)은 대부분 커뮤니티 위키·개발자 인터뷰·Steam 가이드 기반이라 엔지니어링 스펙은 아니다(보통 2개 독립 출처로 교차 확인됨). **기술적 백본은 학술/1차 출처** — 도킨스(PLOS 2024 동료심사), 칼 심스(SIGGRAPH '94 원논문), NEAT(EC02 원논문)가 고신뢰다.
- **단일 출처 항목:** NEAT 게놈/교배/돌연변이(EC02 단일), 표현형 편향(PLOS 단일) — 다만 각 분야의 정전(canonical) 출처다.
- **버전 의존성:** Pokémon IV/운명의 매듭 규칙은 6~9세대(Scarlet/Violet 2022+)에서 안정적이나 버전에 묶인다.
- **반증된 2개 주장(설계에 반영 금지):** ① "Spore는 크리처를 절차 생성하지 않는다"(실제론 함), ② "운명의 매듭이 착용 부모의 IV 5개를 강제 전달한다"(개수만 결정론, 스탯·부모는 랜덤).
- **🔑 범위 경고 (가장 중요):** 이 시스템들은 거의 전부 **개성·번식 게임플레이용이지 과학적으로 정확한 집단유전학(population genetics)이 아니다.** Creatures 제작자조차 "진화 기반 시뮬레이션이 아니다"라고 했다. jvolution이 *진화* 테마로서 **집단 수준 동역학(유전적 다양성, 유전적 부동drift, 근친)**을 원한다면, 이 개체별 번식 모델들은 그것을 직접 제공하지 않는다 — 별도 설계가 필요하다.

## 8. 다음 단계로 풀어야 할 미해결 질문

리서치가 커버하지 못했고 구현 전에 결정해야 할 것들:

1. **KMP 직렬화 전략:** 고정 길이 `IntArray`(Biomorph식) vs 타입드 대립유전자쌍 레코드(Niche식) vs NEAT 레코드 리스트 — 저장 크기, 스키마 버저닝/마이그레이션, 그리고 **발생 함수를 양 플랫폼에서 동일하게 돌리는 결정론** 보장 방법.
2. **계보/다양성 메타 알고리즘:** 혈통(pedigree) 저장, 근친 탐지(kinship/근친계수), 세대 간 다양성 지표의 증분 업데이트 전략 — *출처 없음, 직접 설계 필요.*
3. **하나의 게놈으로 4개 도메인 동시 구동** 시 시스템 간 충돌 회피 + 모바일 런타임 비용(NEAT vs 유전자 가중 행동 트리).
4. **재미를 위한 돌연변이율·우성 규칙 튜닝:** 표현형 편향을 감안해 어떤 값이 "다채롭고·조종 가능하고·보람찬" 번식 공간을 만드는가(Wobbledogs식 안정성 감쇠 포함).
5. **모바일 절차적 외형:** 2D 재귀 벡터(저렴·완전 결정론)로 충분한가, 아니면 3D 부위조립/암시적 표면이 필요한가 — 후자의 KMP 성능·툴링 비용.
