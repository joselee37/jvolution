# Sonar Tamagotchi — 스펙 시트 (Spec Sheet)

CRT/소나(sonar) 관측소 테마의 가상 펫(virtual pet) 게임 **Sonar Tamagotchi**
의 정식 기획·스펙 시트입니다. 현재 동작하는 데모를 역설계해 만든 문서로,
게임의 규칙·수치·콘텐츠를 한곳에 모았습니다.

## 명세 원칙 (Specification Principles)

1. **As-is 명세** — 이 문서는 현재 데모에 *실제로 구현된* 동작만 기술합니다
   (descriptive). 향후 추가하면 좋을 기능이나 개선안은 포함하지 않습니다.
2. **프레임워크 비종속 (framework-agnostic)** — 모든 규칙은 게임 디자인
   명세로 표현되며, 어떤 게임 엔진(Unity, Godot, 순수 JavaScript 등)에서도
   그대로 구현할 수 있습니다. 특정 구현체의 코드 구조·모듈·상태 모델은
   명세에 포함하지 않습니다.
3. **데모에서 추출한 디자인 값** — 문서의 모든 수치(스탯 증감, 확률,
   타이밍, 데미지 등)는 현재 데모에서 직접 추출한 디자인 값입니다.

## 용어 표기

핵심 게임 용어는 첫 등장 시 `한국어 용어(English term)` 형식으로 영어를
병기합니다. 이후에는 한국어 또는 영어 중 문맥에 맞는 쪽을 사용합니다.

## 비주얼 레퍼런스

게임의 비주얼 무드 레퍼런스(영상·스크린샷)는 저장소의 `모티브/` 폴더에
보관되어 있습니다. CRT 군용 계측기·소나 스코프의 질감, 포스퍼(phosphor)
글로우, 스캔라인 등의 톤을 참고할 수 있습니다.
